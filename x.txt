# 🔍 PCIeJ Issue Similarity System

An internal AI-powered tool to automatically detect similar past issues for newly created PCIeJ issues and assist in faster debugging and analysis.

---

## 🚀 Overview

Whenever a new PCIeJ issue is created, this system:

1. Fetches issue details (testcase, error message, description)
2. Converts them into embeddings (semantic vectors)
3. Searches similar past issues using FAISS
4. Applies decision logic (HIGH / MEDIUM / LOW confidence)
5. Returns best match with analysis (optional: auto-update IMS)

---

## 🧠 Key Features

- ✅ Fully offline (VDI compatible)
- ✅ No cloud dependency (company compliant)
- ✅ Semantic similarity using embeddings
- ✅ Hybrid scoring (semantic + keyword)
- ✅ IMS (JIRA) integration
- ✅ Description fetching & cleaning
- ✅ Caching for performance
- ✅ Async API (FastAPI)
- ✅ Feedback loop support
- ✅ Safe auto-update (optional)

---

## 🏗️ Architecture

```
IMS Issue → API → Fetch Description → Embedding → FAISS Search
         → Hybrid Scoring → Decision Engine → Response / Update
```

## ⚙️ Setup (Offline - VDI Compatible)

### 1️⃣ Download dependencies (LOCAL MACHINE)

```bash
pip download sentence-transformers -d offline_packages
```

Download model:

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')
model.save('./model')
```

---

### 2️⃣ Transfer to VDI

Copy:
- `offline_packages/`
- `model/`

---

### 3️⃣ Install dependencies in VDI

```bash
pip install --no-index --find-links=offline_packages sentence-transformers
```

Also install:
```bash
pip install fastapi uvicorn faiss-cpu numpy requests
```

## 📊 Data Preparation

### Input format (`issues.txt`)

```
---ISSUE_START---
issue_id: GR01
testcase: something
error_message: something
analysis: something
status: closed
ims_link: http://...
---ISSUE_END---
```

---

### Convert to JSON

```bash
python -m scripts.parse_txt
```

---

### Generate embeddings

```bash
python -m scripts.generate_embeddings
```

---

### Build FAISS index

```bash
python -m scripts.build_index
```

## 🧠 Decision Logic

| Score | Decision |
|------|--------|
| ≥ 0.93 | HIGH_CONFIDENCE |
| ≥ 0.82 | MEDIUM_CONFIDENCE |
| < 0.82 | LOW_CONFIDENCE |

---

## 🔥 Accuracy Improvements

### ✅ Weighted Embedding
- Error + Testcase repeated for importance

### ✅ Description Cleaning
- Noise removed
- Length limited

### ✅ Hybrid Scoring
```
Final Score = 0.7 * semantic + 0.3 * keyword
```

### ✅ Text Normalization
- Lowercase
- Remove numbers
